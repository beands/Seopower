# Анализ конкурентов

Разделяй business competitors и search competitors.

Для 5–20 приоритетных кластеров:
1. Получи SERP в правильном регионе.
2. Собери повторяющиеся домены.
3. Определи page type.
4. Выбери 3–7 search competitors.
5. Сравни shortlist URL.

Для каждой SERP-выборки зафиксируй query, поисковик, регион, устройство, дату/время, первые результаты, SERP features и raw artifact. Не экстраполируй один запрос на весь кластер, если намерение или page type различаются.

Сравнивай offer, ассортимент, цены/условия, trust, UX, content modules, FAQ, local proof, internal links, schema, media, conversion path, freshness.

Gap analysis: недостающие услуги/темы/page types, слабый UX, отсутствие proof/local coverage, плохой bridge informational → commercial.

Не делай вывод «у конкурента 3500 слов — нам нужно 4000». Не копируй структуру 1:1.

Не выдавай публично наблюдаемый контент конкурента за подтверждённые метрики трафика, ссылок, конверсии или выручки. При слабой выборке рекомендация остаётся гипотезой с планом проверки.

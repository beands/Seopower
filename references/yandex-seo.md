# Яндекс: обязательный слой RU SEO

## Wordstat
Используй текущий Wordstat API через Yandex Search API, если доступен. Собирай top requests, associations, dynamics, regions и device split, если его поддерживает инструмент. Показы не равны прогнозу кликов.

Для каждого важного запроса проверяй SERP intent.

**Проверка:** сохрани период, регион, устройство, тип отчёта и исходный экспорт в evidence register. Если Wordstat недоступен, используй публичную SERP-выборку только для intent и формулировок; не оценивай частотность.

## Yandex Search API / SERP
SERP нужен для проверки intent, кластеризации, поиска search competitors, сравнения шаблонов и региональной зависимости. Для RU-проектов используй русский тип поиска и корректный region id, если инструмент это поддерживает. Один SERP не универсален для всей России.

**Минимальная выборка:** query, дата/время, регион, устройство, первые результаты и доминирующий page type. Остановись и пометь ограничение, если регион/устройство нельзя задать или выдача содержит персонализацию, которую нельзя описать.

## Yandex Webmaster
При наличии доступа анализируй:
- диагностику;
- robots/sitemap;
- региональность;
- индексацию и причины исключения;
- важные URL;
- поисковые запросы;
- CTR/клики/показы/позиции;
- query → URL;
- broken internal links;
- изменения страниц в поиске.

Recrawl и иные write-операции требуют подтверждения пользователя.

Не называй URL «не в индексе» по одной публичной проверке. Без Вебмастера допустима только формулировка «не подтверждено в доступной выборке» и следующий шаг — экспорт или доступ read-only.

## Региональность
Для геозависимого бизнеса сверяй фактический адрес/географию на сайте, регион Вебмастера, Яндекс Бизнес и региональные страницы. Не назначай регион, который бизнес не может подтвердить. Региональность — сигнал, а не гарантия позиции.

## Яндекс Метрика
Минимум:
- organic sessions/users;
- поисковые системы;
- organic landing pages;
- business conversions;
- device split;
- сравнение периодов;
- сезонность.

При API-выгрузке явно указывай период, исключай роботов, фиксируй атрибуцию и sampling/accuracy, если применимо.

## ИКС
Отслеживай как дополнительный индикатор. Не используй ИКС как прямой KPI ранжирования. Главный KPI — целевой органический трафик и конверсии.

## Контент
Проверяй полезность, оригинальность, понятность, доступность без скрытых действий, отсутствие переспама, реальную коммерческую ценность и актуальность.

Не советуй «увеличить текст до N символов» без причины, подтверждённой intent/SERP.

## Актуальность
При изменениях API, региональности, schema или требований сверяйся с текущей официальной документацией Яндекса.

Перед использованием изменяемого правила проверь `references/source-registry.md`. Просроченная запись требует свежего первичного источника и обновления реестра.

# Intake / профиль маркетинга клиента

Пошаговый сценарий вопросов и правила адаптивного диалога находятся в `references/onboarding-flow.md`. Он обязателен: сначала исследуй доступные материалы, затем задавай не более 3–5 критичных вопросов за раунд.

## Принцип
Не задавай длинный список вопросов подряд. Сначала прочитай сайт, sitemap, контакты, карточки и доступные аналитические данные. Затем спроси только то, чего нельзя надёжно определить.

## Минимум для старта
1. Домен.
2. Главный продукт/услуга.
3. География: город/область/Россия/СНГ/несколько стран.
4. Главная бизнес-конверсия.
5. Приоритетные или маржинальные направления.
6. Статус каналов: поиск/сайт, реклама, соцсети, маркетплейсы, локальные профили, CRM/удержание.
7. Доступные агрегированные выгрузки: Метрика, Вебмастер, GSC, рекламные кабинеты, маркетплейсы, CRM/телефония; не требуй API-доступа.
8. Известные конкуренты.

## Полный onboarding
### Бизнес
- публичное название;
- отрасль;
- продуктовые линии;
- средний чек/ценовой диапазон;
- цикл сделки;
- ограничения продаж;
- сезонность;
- подтверждённые средний чек, выручка/маржа и бюджеты с периодом;
- ресурсы команды и ограничения fulfillment;
- запрещённые/нежелательные темы.

### География
- основной регион;
- реальные офисы/точки;
- service area;
- доставка/выезд;
- города с отдельным предложением;
- языки.

### Аудитория
- B2B/B2C;
- роли принимающих решение;
- боли;
- критерии выбора;
- возражения.

### Конверсии
Звонок, форма, заказ, корзина, мессенджер, визит, регистрация, скачивание и прочие macro/micro goals.

### Каналы и измерение
- Статус ACTIVE / PLANNED / NOT_USED / NOT_APPLICABLE / UNKNOWN для каждого направления из `references/marketing-channels.md`.
- Доступные расходы, показы/просмотры, переходы, обращения, квалифицированные лиды, заказы, выручка, маржа и повторы с периодом и определениями.
- CRM, телефония/call tracking, обработка лидов, причины потерь, возвраты/отмены.
- Attribution window и ограничения платформенной атрибуции.

### Сайт
CMS/stack, недавние миграции, поддомены, зеркала, SPA/SSR, языковые/региональные версии, доступ к репозиторию при технической работе.

### Контент
Tone of voice, реальные эксперты, кейсы, сертификаты, лицензии, фото/видео, данные, которые можно публиковать.

### SEO-история
Старый подрядчик, ссылочные схемы, массовые автотексты, санкции, падения трафика, редизайны, миграции.

## Результат
Создай `client-profile.md` по шаблону `assets/client-profile.template.md`. При полном аудите заполни статус всех каналов; неизвестные значения остаются `UNKNOWN`.
Для каждого факта используй статус: VERIFIED / PROVIDED_BY_CLIENT / INFERRED / UNKNOWN.

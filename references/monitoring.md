# Monitoring & SEO drift

Для полного marketing-аудита сохраняй определения, периоды, источники и покрытие по каналам отдельно. Сравнивай funnel stages, расходы, qualified leads, orders, revenue/margin, повторные продажи и возвраты только там, где источник и attribution сопоставимы. Unknown/partial coverage не означает нулевое значение.

## Baseline
Дата, crawl count, indexed count, top queries, top landing pages, organic traffic, conversions, regions, technical issues, target clusters, local profile state.

## Comparison
WoW только для быстрых сигналов, MoM, YoY для сезонных ниш.

## Alerts
Резкое падение clicks/impressions, массовая потеря index pages, 4xx/5xx, robots/noindex/canonical drift, sitemap errors, изменение региона, исчезновение money page, падение organic conversion, смена target URL, local profile issues.

## Diagnosis order
1. tracking;
2. availability;
3. robots/noindex/canonical;
4. indexation;
5. releases/migrations;
6. query/URL losses;
7. SERP/competitors;
8. seasonality;
9. content decay;
10. algorithm hypotheses.

Не объясняй падение «апдейтом алгоритма», пока не проверены собственные причины.

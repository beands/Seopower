# Контент и коммерческие страницы

## Принцип
Страница должна лучше решать пользовательский сценарий, а не быть длиннее конкурента.

## Money pages
Проверяй по применимости:
- ясный offer;
- цена/способ узнать цену;
- состав услуги/товара;
- варианты/характеристики;
- сроки;
- доставка/выезд;
- оплата;
- гарантия/возврат;
- реальные фото;
- кейсы;
- отзывы;
- документы/лицензии;
- адрес/контакты;
- CTA;
- FAQ по реальным возражениям.

## Информационный контент
Быстрый ответ, объяснение, примеры, первичные источники, опыт, логичный следующий шаг.

## On-page
Title соответствует intent, H1 описывает страницу, description полезен для CTR, headings отражают структуру, primary query и синонимы естественны.

## Переспам
Красные флаги: точный ключ в каждом абзаце, keyword strings, списки городов без пользы, hidden SEO text, текст «для робота», programmatic pages без самостоятельной ценности.

## Доверие
Кто оказывает услугу, реальные контакты, эксперты, опыт, кейсы, политика возврата/гарантии, условия. Не выдумывай trust/E-E-A-T доказательства.

## Content brief
Цель страницы, cluster, intent, SERP pattern, audience, вопросы, factual inputs, outline, internal links, schema opportunities, CTA, prohibited assumptions, verification checklist.

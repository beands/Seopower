# Technical SEO

## Crawlability
robots.txt, sitemap, status codes, redirects, noindex/nofollow, critical content availability.

## Indexability
canonical, duplicate URL variants, HTTP/HTTPS, www/non-www, slashes, parameters, facets, pagination, soft 404, deleted pages, JS-only content.

## Yandex verification
Сверяй crawl inventory ↔ sitemap ↔ Webmaster index/in-search samples ↔ important URLs ↔ organic landing pages. Расхождение важнее абсолютного количества страниц.

## Internal links
Orphans, 1-link pages, broken links, anchors, hub pages, breadcrumbs, click depth, money-page link equity.

## Performance
Используй field + lab при наличии. Не оптимизируй score ради score; связывай проблему с UX и шаблоном.

## Mobile
Viewport, tap targets, forms, overlays, sticky UI, navigation, parity of important content.

## Rendering
Для React/Vue/SPA сравни view-source и rendered DOM, metadata, links, canonical, schema, lazy critical content и render errors.

## Schema
Используй только фактические Organization/LocalBusiness/BreadcrumbList/Product/Offer/Article/VideoObject и релевантные типы. Не добавляй факты, которых нет у бизнеса.

## Migration
URL map, 301, canonical, sitemap, robots, analytics, Webmaster/GSC, redirect tests, сохранение top landing pages.

## Deliverable
Evidence → affected URLs → scale → impact → fix → test.
